# Capstone Thesis for Overleaf

This folder is an Overleaf-ready LaTeX project for the capstone thesis:

**Layer Contrastive Decoding and Epistemic Reliability Estimation for Hallucination Aware Small Language Models**

## Upload to Overleaf

1. In Overleaf, select **New Project** then **Upload Project**.
2. Upload this folder as a ZIP file, or upload all files while preserving the `figures/` folder.
3. Set `main.tex` as the main document if Overleaf does not detect it automatically.
4. Compile with pdfLaTeX.

## Required updates before submission

Replace the following marked fields in `main.tex`:

- Each `[UPDATE REGISTRATION NUMBER]`
- `[UPDATE HOD NAME]`
- Examiner names and signatures after review
- Date, if your final submission month differs

The project is intentionally evidence-conscious: results stated in the thesis come from the supplied research paper and distinguish active implementation facts from archived results whose upgraded trainer source is unavailable.
